# Hello World

A small Vite + React + TypeScript site using shadcn/ui components and Tailwind CSS.

## Local development

Run `npm install` once, then `npm run dev` to start the local Vite server. Edit `src/App.tsx` for the page and `src/components/ui/` for the shadcn components. Run `npm run build` to produce the static site in `dist/`.
